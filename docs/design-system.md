# Design System — GalleryLedger

> Generated by Design Overhaul skill. This document is the single source of truth for all design decisions.

## Design Direction

**Direction:** The Vault — Ultra-refined archive elegance, where art meets precision
**Signature Element:** Spotlight reveal animations — radial light bloom on entry, gold luminance on hover

## Animation

| Token | Value | Usage |
|-------|-------|-------|
| --duration-fast | 150ms | Micro-interactions (hover, focus) |
| --duration-normal | 300ms | State transitions |
| --duration-slow | 500ms | Page transitions, reveals |
| --easing-default | cubic-bezier(0.4, 0, 0.2, 1) | General motion |
| --easing-spring | cubic-bezier(0.22, 1, 0.36, 1) | Smooth entrances |
| --easing-out | cubic-bezier(0, 0, 0.2, 1) | Exit animations |

**Signature Animation:** Spotlight reveal — elements enter with opacity 0 + filter blur(8px) → opacity 1 + blur(0), combined with a soft radial warm-light bloom behind. Interactive elements emit gold box-shadow pulse on hover (0 0 20px rgba(184,149,106,0.12) → 0.2).
